# Patreon Post Workflow & Iteration Process

**Purpose:** Guide for creating, refining, and publishing Patreon posts through iterative improvement

---

## 📝 Post Creation Workflow

### Step 1: Initial Draft
1. **Gather Information:**
   - Check branch status (use `BRANCH_MONITORING.md`)
   - Review recent commits and changes
   - Check project management dashboard
   - Note key achievements and milestones

2. **Create Draft:**
   - Use template from `PATREON_UPDATES.md`
   - Write in `community-management/patreon/drafts/`
   - Name: `PATREON_UPDATE_[DATE]_DRAFT.md`

3. **Initial Review:**
   - Check tone and voice (see `WRITING_GUIDELINES.md`)
   - Ensure all required sections included
   - Verify accuracy of technical details

### Step 2: First Iteration
1. **User Review:**
   - User provides feedback
   - Notes areas to improve
   - Suggests additions/removals

2. **PM Agent Updates:**
   - Incorporate feedback
   - Refine language
   - Add missing information
   - Improve flow and readability

### Step 3: Subsequent Iterations
1. **Iterative Refinement:**
   - User reviews updated version
   - Provides additional feedback
   - PM Agent makes further improvements
   - Repeat until satisfied

2. **Final Polish:**
   - Proofread for typos
   - Check formatting
   - Verify all links work
   - Ensure screenshots/visuals are ready

### Step 4: Approval & Publishing
1. **Final Approval:**
   - User approves final version
   - Move to `published/` folder
   - Archive in `PATREON_UPDATES.md`

2. **Publishing:**
   - Copy to Patreon
   - Add any final touches
   - Schedule/post

---

## 🔄 Iteration Checklist

### Content Review
- [ ] Story flows well
- [ ] Technical details accurate
- [ ] Progress metrics correct
- [ ] Tone appropriate
- [ ] Engaging and interesting

### Structure Review
- [ ] All required sections present
- [ ] Logical flow between sections
- [ ] Good balance of technical/non-technical
- [ ] Appropriate length

### Language Review
- [ ] Clear and understandable
- [ ] No jargon without explanation
- [ ] Conversational tone
- [ ] Enthusiastic but realistic

### Visual Review
- [ ] Screenshots included (if ready)
- [ ] Visuals enhance the story
- [ ] Formatting is clean
- [ ] Links work correctly

## 💡 Best Practices

### During Iteration
1. **Be Responsive:** Update quickly after feedback
2. **Track Changes:** Note what changed between versions
3. **Maintain Tone:** Keep voice consistent
4. **Stay Accurate:** Verify all technical details
5. **Be Flexible:** Willing to restructure if needed

### Communication
1. **Clear Feedback:** User provides specific feedback
2. **Quick Updates:** PM Agent updates promptly
3. **Version Control:** Track versions clearly
4. **Status Updates:** Keep user informed of progress

## 🔍 Monitoring During Development

### While Other Agent Works
1. **Check Branch Status:**
   - Run branch monitoring script
   - Review `BRANCH_MONITORING.md`
   - Note progress on match engine

2. **Update Post Draft:**
   - Incorporate new progress
   - Update metrics
   - Add new achievements

3. **Keep Post Current:**
   - Regular updates as work progresses
   - Note milestones as they're reached
   - Update timelines if needed
