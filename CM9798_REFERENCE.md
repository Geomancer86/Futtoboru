## 3. Expansions & seasonal products

CM9798 is **not** an expansion — it is a **standalone seasonal SKU** on the CM2 engine.

| Product | Relationship |
|---------|--------------|
| **CM2** (1995) | Base engine |
| **CM 96/97** | Prior seasonal data pack on same engine |
| **European Leagues CD** (1996) | Foreign league **install folders** — still compatible with CM2/9798 ecosystem |
| **CM97/98** | **Final** CM2-engine retail product |
| **CM3** | Replacement engine — not a data disk for CM9798 |
