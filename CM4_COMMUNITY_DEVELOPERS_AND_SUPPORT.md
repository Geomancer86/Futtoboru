## 1. Development story

### 1.1 Project profile

| Field | Detail |
|-------|--------|
| **Codename / brand** | CM4, CM 2002–03 season data |
| **Started** | After CM01/02 success; delayed from original 2002 target |
| **Scope** | **Full codebase rewrite** — not seasonal DB swap |
| **Team size (credits)** | **1,613** credited (1,559 developers + 54 thanks) — MobyGames |
| **Consultants** | Jask Consultants, Direct Surf, Spike Island Games (programming support) |
| **Mac port** | **Feral Interactive** — 17 May 2003 EU |

### 1.2 Key people

| Person | Role on CM4 |
|--------|-------------|
| **Paul Collyer** | Co-founder SI; design leadership |
| **Oliver Collyer** | Co-founder; background role post-2001 |
| **Marc Vaughan** | Head of Development; **2D match engine architecture**; tactical AI; public FAQs (IGN walkthrough credits Mark Vaughan late-game tactic) |
| **Ray Houghton** | **Consultant** — ex-pro; advised **2D match engine realism** and **training regimes** ✅ multiple sources |
| **Chris Rowley, Gareth Spencer, Jason Walker** | Long-tenure SI staff (MobyGames collaboration chains → FM2010+) |
| **Research volunteers** | ~global network; stats ownership separate from programmers (Vaughan interview) |

### 1.3 Design intent (SI / press)

- **2D engine:** Visual feedback like pro **Prozone** analysis — see full-back beaten live (PC GamesN).  
- **Rewrite justification:** CM3 text engine couldn't show tactical failure modes.  
- **Windows XP** UI refresh; **skinnable** interface for community branding.  
- **Ray Houghton:** Bridge between mo-cap movement realism and management sim abstraction.

### 1.4 Launch crisis

| Issue | Impact |
|-------|--------|
| **Rushed release** | Multiple delays then Mar 2003 ship still buggy |
| **Save corruption** | Worst bugs — lost saves; fan exodus |
| **Training stars broken** | Training appeared useless in 4.0.0 |
| **Wage inflation bug** | Top clubs wages explode after season |
| **Missing promised features** | ActiveGaming review notes gaps vs pre-release promises |

**SI response:** **Enhancement Pack 1 released launch day** (29 Mar 2003) — unusual same-day patch culture born.

**Community verdict:** "Buy CM4 + EP mandatory; many prefer wait for **CM03/04**" — MobyGames player review consensus.

## 2. Official support & Enhancement Packs

### 2.1 Enhancement Pack timeline

| EP | Version | Release | Highlights |
|----|---------|---------|------------|
| **EP1** | 4.0.3 | 29 Mar 2003 | Wage bug; rehab timeout; Swedish derby stadia; Euro symbol Ter skin; **praise/criticise media** |
| **EP2** | 4.0.4 | 11 Apr 2003 | Essential minimum per community FAQ |
| **EP3** | 4.0.5 | ~May 2003 | Injury fixes; optional **data update** |
| EP4 | 4.0.7 | 2003 | Intermediate cumulative fixes |
| **EP5** | **4.0.8** | **24 Jul 2003** | **Final** CM4 patch; NO DATA + Updated Data variants |

**EP5 notes (Gamepressure / cmrev.com):**

- Cumulative — install EP5 only, skip EP1–4  
- NO DATA = code fixes only (~28 MB)  
- Updated Data = code + minor player dataset refresh (~46 MB)  
- Compatible with old saves but **new game recommended**  
- **No further CM4 patches planned** — CM03/04 announced Nov 2003 (Dobbers FAQ)

### 3.3 Recommended community install recipe (Soccer Gaming)

1. Install retail CM4  
2. Apply **Enhancement Pack 5** (no prior EP needed)  
3. Optional: Nygreen pre-game editor  
4. Optional: Simon Treanor or CM Sorted data update  
5. Start **new game** after patches  

### 3.4 CM4 → 03/04 community migration

When **CM Season 03/04** shipped (Nov 2003):

- Many fans switched for stability + **match replay**  
- CM4 EP5 remained playable but declined  
- Split **April 2004**: SI → FM2005; Eidos → CM5 (failed)  
- Community bifurcated: **Champman0102 → FM** vs residual CM4 holdouts

## 8. Legacy & influence on Football Manager

CM4 innovations carried to **FM2005+**:

- 2D match engine (FM2009 adds 3D option)  
- Training schedules  
- Personalities / morale depth  
- Fan vs board expectations  
- Wage + transfer budgets  
- Skin modding → FM skin community  

**SI kept:** code, database, researchers. **Eidos kept:** "Championship Manager" name → CM5 disaster.
