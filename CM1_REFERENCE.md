| Field | Detail | Source |
|-------|--------|--------|
| **Developer** | Paul & Oliver Collyer (Intelek) | Wikipedia, MobyGames |

| **Platforms** | Amiga, Atari ST, MS-DOS | ✅ |
| **Genre** | Football management simulation | ✅ |
| **Predecessor** | Collyers' BBC Micro league tracker (1983) | Grokipedia |

| **Launch sales** | ~**20,000** copies — modest | Wikipedia ⚠️ |
| **Reception** | Positive for depth; perceived as complex/text-heavy | Amiga reviews |

### Origin story (developers)

- Teenage brothers in **Shropshire** built prototype from bedroom; rejected by multiple publishers before **Domark** accepted.  
- Paul handled core programming; Oliver expanded **player attributes** beyond basic skill/pace.  
- Data sourced from publications like **Rothmans Football Yearbook** ⚠️.  
- **No formal company** until Sports Interactive registered **1994** (often cited as 1995 registered).  
- Collyers later inserted themselves as **below-average players** in database Easter eggs (MobyGames tradition).

## 2. Match engine & presentation

| Aspect | CM1 implementation |
|--------|-------------------|
| **Engine type** | **Text-only** scrolling match commentary |
| **Visual pitch** | None |
| **Backgrounds** | Digitised ground photos (later SVGA in CM2) — CM1: attractive backdrops per Amiga review |
| **Player ratings** | **0–10 average after each match** — **first in genre** ✅ |
| **Match flow** | Week split weekday/weekend; press **Done** to advance time |
| **Interruption** | Could interrupt commentary for subs/tactics (limited vs later CM) |

### Competitions

- **Domestic:** FA Cup, League Cup, Anglo-Italian Cup, full English pyramid  
- **European:** 3 competitions including **Cup Winners' Cup**  
- **International:** Not fully simulated as manager career |

## 4. Core gameplay systems

### 4.1 Management loop

1. New game or load season disk  
2. Pick club (hotseat up to 4 managers)  
3. Set tactics / lineup  
4. Advance week → match text → ratings  
5. Transfers, squad trim between matches  
6. Season ends with champion — **full loop existed in CM1** ✅

### 4.2 Tactics

- Formations and team selection via menus  
- Mouse-driven large text boxes  
- No per-player instruction depth of CM3+

### 4.3 Transfers

- Approach players; club acceptance; wage/contract negotiation  
- Domestic focus; overseas players handled separately  
- No formal transfer windows

### 4.4 Training

- **Minimal to none** — no CM3-style schedules  
- Fitness and morale tracked

### 4.5 Board & job security

- Basic board expectations  
- **Resign** option from main menu  
- Sacking for poor performance (basic)

### 4.6 Multiplayer

- **Hotseat up to 4 players** on one machine ✅ (manual confirms)

### 4.7 Save system

- Requires **blank formatted season disk** (Amiga/ST)  
- Reusing disk **wipes prior season** — manual warns explicitly
