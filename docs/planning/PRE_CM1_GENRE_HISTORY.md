## Executive summary

Football management simulation did **not** begin with Championship Manager. The genre was **invented by Kevin Toms'** *Football Manager* (**1982**). The Collyer brothers built an independent line starting from a **BBC Micro league tracker (1983)** and shipped **CM1 in 1992** — the same year Toms' line ended with *Football Manager 3*.

| Milestone | Year | Significance |
|-----------|------|--------------|
| **Soccerama** board game | 1968 | Early tabletop season + divisions simulation |
| **Kevin Toms board game** | ~1970s (age 11) | Inspired by Soccerama; cereal-box prototypes |
| **Football Manager (Toms)** | **1982** | **First commercial football management video game genre** |
| **Collyer BBC tracker** | **1983** | Radio results → league tables; CM/FM spiritual ancestor |
| **Football Manager 2** | 1988 | Toms sequel; 500k+ copies in first 6 years (original FM) |
| **Premier Manager** | 1992 | Gremlin; Conference→top flight; 4-player hotseat |
| **The Manager** | 1992 | US Gold; English reskin of Bundesliga Manager |
| **CM1** | **1992** | Collyers; 4 divisions, cups, Europe; **anonymous English players** |
| **Football Manager 3** | 1992 | Toms line ends (poor sales) |

**Futtoboru takeaway:** v1 needs **CM1 loop** (season, rules, champion), not CM3 depth. Genre proof is **Toms 1982**: text + table + cups + multi-season is enough to be a product.

## Part 1 — Board games (pre-computer)

### 1.1 Soccerama (1968)

| Field | Detail | Confidence |
|-------|--------|------------|
| **Publisher** | ASL Pastimes (UK) | ✅ Super Chart Island / Wikipedia via Toms |
| **Type** | Football **management** board game | ✅ |
| **Mechanics** | Dice-driven scores; simulate **FA Cup and full seasons**; promotion from **4th to 1st division** | ✅ |
| **Money** | Monopoly-style cash (limited strategy) | ⚠️ Super Chart Island |
| **Endorsement** | Later editions: **Alan Ball** quote on box | ⚠️ Super Chart Island |
| **Legacy** | Direct inspiration for Kevin Toms age ~11 | ✅ Wikipedia, Toms interviews |

Soccerama established the **core fantasy**: not playing matches on a pitch, but **running a club through a season** with promotion/relegation.

### 1.2 Other tabletop influences (Kevin Toms)

From [Super Chart Island](https://superchartisland.com/football-manager/) and Toms interviews:

| Game | Role |
|------|------|
| **Wembley** | Popular football board game of era |
| **Subbuteo** | Toms ran street **Subbuteo league** (8 kids, fixture list, won as West Ham) |
| **Toms' own board design** | Age 11; career advisor told parents "just a phase" |

Toms wanted to fix board games' weakness: **manual league table and fixture calculation**. Computers solved that.

### 1.3 Other board/strategy games (context only)

| Product | Notes |
|---------|-------|
| **Chartbusters** (ASL) | Pop music chart simulation — same publisher family as Soccerama |
| Generic football dice games | Score-only; not management genre |

### 2.2 Football Manager (1982) — genre birth

| Field | Detail |
|-------|--------|
| **Release** | **January 1982** (mail order); Spectrum version Sep 1982 in shops | ✅ |
| **First platform** | Video Genie (TRS-80 clone) → ZX81 → **ZX Spectrum** (+ highlight graphics) |
| **Language** | **BASIC** entirely | ✅ Wikipedia |
| **Sales** | **500,000** in first 6 years; **~2 million** lifetime across series | ✅ Wikipedia, StoryBundle |
| **Distribution** | Mail order ads (Computer & Video Games Jan 1982); WH Smith after Spectrum | ✅ Eurogamer |

#### Gameplay systems (FM 1982)

| System | Detail |
|--------|--------|
| **Goal** | Take any team from **Division 4 → Division 1**; win **FA Cup**; play forever |
| **Roster** | Random squad per team (names real but not accurate to club); max **16** players |
| **Player stats** | Skill **1–5**; Energy **1–20** |
| **Team ratings** | Defence / Midfield / Attack aggregates; morale; energy average |
| **Season drift** | Skills **randomly change** end of season (Toms: keep challenge) | ✅ Wikipedia |
| **Match** | Text; Spectrum+ has **isometric highlight** animations when goals scored |
| **In-match control** | **None** during match — watch only |
| **Finances** | Weekly income/expenditure; **bank loans** by division (£250k–£1M limits) |
| **Transfers** | Random players offered; bid; list for sale; accept/reject |
| **Rest / injury** | Rest to restore energy or injury |
| **Save** | Any time |
| **Customizer** | Rename teams and players | ✅ |
| **Memory limit** | ZX81: **8-character names** — Southampton excluded | ✅ Wikipedia |

#### Reception (FM 1982)

| Source | Quote / note |
|--------|--------------|
| Electron User | "One of the best strategy games"; "doubt … ever be bettered" |
| Golden Joystick 1983 | Best strategy — **2nd** to *The Hobbit* |
| Your Sinclair 2004 | **26th best game of all time** |
| Amiga Power 1991 | 19% score but "still massively addictive" "classic" |

## Part 3 — Collyer brothers (parallel origin)

### 3.1 BBC Micro league tracker (~1983)

**Paul Collyer**, Shropshire (rural; poor TV signal — no Teletext):

> "I would listen to the radio to get the results, then type them in to the computer and it would update the league tables on the screen. That was my first venture into football programming."

| Aspect | Detail |
|--------|--------|
| **Platform** | BBC Micro | ✅ Wikipedia |
| **Function** | Manual result entry → **automatic league table** | ✅ |
| **Relation to Futtoboru** | Closest historical analogue to **1888 mod + standings** | Design note |

### 3.2 Path to CM1 (1983–1992)

| Step | Detail |
|------|--------|
| Teenage bedroom coding | Paul + Oliver; expanded attributes beyond Toms' skill/pace |
| **European Championship** working title | MobyGames SI: first name before CM |
| Publisher rejections | Multiple; **EA rejected** — "not enough live action" (text only) |
| **Domark** | Accepted; published CM1 |
| **Intelek** | Developer credit on box (Collyer vehicle) |
| **Sports Interactive** | Formalised **July 1994** (registered 1995) |

### 3.3 Collyers vs Toms (legal/code)

| | Kevin Toms FM | Collyer CM/FM |
|--|---------------|---------------|
| **Code** | Separate BASIC lineage | Separate C/BASIC rewrite |
| **First ship** | 1982 | 1992 |
| **Name "Football Manager"** | Toms 1982–1992 | SI acquired **2003** after Eidos split |
| **Depth** | 4 div promotion game | 4 div + cups + Europe + 1500 players |
| **Player names** | Real-ish random squads | **Anonymous** in English leagues CM1 |

**Not the same franchise** until SI renamed post-2003.

## Part 5 — The 1992 market (CM1 launch year)

Four major English management sims shipped **the same year**:

| Game | Publisher | Database | Player names | Hotseat | Distinctive |
|------|-----------|----------|--------------|---------|-------------|
| **CM1** | Domark | 4 English divs; ~1500 players | **Anonymous** in league | **4** | European cups; **0–10 ratings** innovation |
| **Premier Manager** | Gremlin | Top 5 divs + Conference + part-time | Real 92/93 season | **4** | Training, tactics, sponsors, stadium |
| **The Manager** | US Gold | Full **91/92** English league | Real names | ? | German engine reskin; sponsors |
| **FM3** | Addictive/Prism | — | — | — | **Last Toms line; failed** |

### CM1 launch reception vs competitors

| CM1 | Detail |
|-----|--------|
| Sales | ~**20,000** — modest vs FM's millions | ✅ Wikipedia |
| Reviews | **81–89%** Amiga (The One 89%, CU Amiga 84%) | ✅ Amiga Magazine Rack |
| Weakness cited | **Wrong league sizes** (20 not 22/24); **fake names**; **Domark Trophy** self-promo | ✅ Amiga Reviews |
| Strength cited | Depth, cups, stats, **video printer**, playability | ✅ |
| Marketing | **Graeme Souness** Daily Mirror quote May 1992 | ✅ Wikipedia |

**Historical irony:** CM1 lost on **realism** to Premier Manager / The Manager in 1992, then won on **depth + updates** (CM2, CM97/98, CM3).

## Part 8 — Futtoboru design implications

### What pre-CM1 proves

1. **Genre viability without graphics** — Toms 1982 text-only sold millions.  
2. **Table + fixture automation** is the core hook (Toms' reason for computers; Collyer BBC tracker).  
3. **Multi-season infinite play** expected since 1982.  
4. **CM1 is the right v1 benchmark** — not CM3/CM4.

### Futtoboru vs CM1 (v1 target)

| CM1 had | Futtoboru needs |
|---------|-----------------|
| Season completes | ❌ **P0** |
| Correct league rules | ❌ **P0** (1888 2-1-0) |
| Champion + table | ⚠️ partial |
| Cup competitions | ⚠️ optional v1 |
| 0–10 ratings | ❌ P1 |
| Hotseat 4 | ❌ defer |
| Anonymous vs real names | ✅ **Real 1888 names** (ahead of CM1) |
| Save game | ⚠️ partial |
