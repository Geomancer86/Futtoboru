## Key Research Findings

### Peak 2D Era: Football Manager 2008

**Historical Context:**
- **FM 2008 (October 2007):** Last version with ONLY 2D engine
- **FM 2009:** Introduced 3D, 2D retained as option
- **FM 2015:** Peak 2D quality in later versions
- **FM 2026:** 2D quality declined (oversized blobs, reduced detail)

### What Made FM 2008 Great

1. **Simplicity:** Colored circles ("blobs") for players
2. **Tactical Clarity:** Perfect top-down view
3. **Match Flow:** Seamless match day experience
4. **Real-Time Adjustments:** Change tactics during match
5. **Mini Radar:** Monitor match while adjusting
6. **Performance:** Fast, smooth, accessible
7. **Abstract Representation:** Imagination factor
8. **Team Color Coding:** Easy identification

### Design Principles for Futtoboru

1. **Simplicity First:** Simple visuals work best
2. **Tactical Clarity:** Full pitch visible, clear formations
3. **Performance Priority:** Fast, smooth, accessible
4. **Focus on Strategy:** Tactics over graphics
5. **Abstract Representation:** Let imagination fill details
6. **Match Flow:** Seamless experience
7. **Real-Time Adjustments:** Change tactics during match

## Key Design Decisions

### Visual Design
- **Player Representation:** FM 2008 style colored circles ("blobs")
- **Team Colors:** Match kit colors for easy identification
- **Pitch View:** Top-down, full pitch visible
- **Ball:** Simple white circle
- **Design Philosophy:** Simplicity, clarity, tactical focus

### Features
- **Match Flow:** Seamless match day experience
- **Mini Radar:** Monitor match during tactical changes
- **Real-Time Adjustments:** Change tactics during match
- **Tactical Clarity:** Perfect for analysis
- **Performance:** Fast, smooth, accessible

### Historical Accuracy
- **1888 Rules:** Offside (2 opponents), no penalty kicks
- **Pitch Dimensions:** Variable 1888 dimensions
- **Formations:** 2-3-5 Pyramid (1888 common)
- **Tactics:** Period-appropriate
