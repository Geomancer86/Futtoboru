# Glossary (draft)

**Status:** Draft · 2026-06-30  

| Term | Definition |
|------|------------|
| **Fit / Fitness %** | Short-term physical readiness (0–100). Reduced by matches; restored by rest. |
| **Sharp / Sharpness %** | Match readiness from recent playing time (0–100). |
| **Mor / Morale %** | Confidence from results and performance (0–100). |
| **Fatigue** | Hidden load from recent matches; high fatigue slows fitness recovery and raises injury risk. |
| **Injury** | Knock that blocks selection until the return date. |
| **Starting XI / Best XI** | Eleven players used in the match simulation for your club. |
| **Return date** | Calendar date when an injured player becomes selectable again. |
| **0–10 rating** | Post-match performance score on the result screen (your squad). |

See [06-squad-and-condition.md](06-squad-and-condition.md) for detail.
