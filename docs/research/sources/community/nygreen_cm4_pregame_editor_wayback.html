CM 4 Pregame Editor

This is the first version of my pregame editor for CM4, it is, as indicated by the version number, in the very early stages of development. So make sure to backup your data files before editing anything, 'cause the program might end up corrupting your data files.

The files you need to make a backup of are server_db.dat and people_db.dat, both are located in the data subdirectory of your CM4 installation.

Features:

The editor is beginning to include a lot of very usefull features. Staff editing is now almost completely implemented, the only major parts missing are Loans and Future Transfers, these will hopefully soon be added. Besides this, some editing of clubs are now also possible. Some important features like changing names and divisions for clubs still haven't been implemented.

This version also includes a search feature for players and clubs, which will make it a lot easier to find the players you want to edit.

Nation, stadium etc editing will be added in later versions.

New Features In This Version:
  • Non Player and Referee attributes
  • Edit Staff Preferences
  • Add and Delete Staff
  • Some club editing
  • Search feature for staff and clubs

Notes:

If you want to distribute your updates only two files need to be distributed: server_db.dat and people_db.dat.

This program doesn't make any updates to client_db.dat yet, this means you might not be able to run a network game with the updated version of server_db.dat. I haven't tested this yet so I have no idea what will happen if you were to try it.
