Small bug fix for 0.04

A small bug had found its way into version 0.04 of the Pregame Editor. Sometimes after loading or saving the status window would stay open, with the message Creating Club List. The program would still work, but the annoying status window would always stay open.

This has been fixed in version 0.04b, so go download that now.

CM 4 Pregame Editor 0.04 released

Version 0.04 of the pregame editor has finally been released.

A lot of great new features has been added in this version, most importantly it is now possible to add and delete staff. Some basic editing of clubs has been added. It's now also possible to search for players, which will make it a lot easier to find the players you want to edit.

Posted by Michael Nygreen 05-05-2003 23:18

CM 4 Pregame Editor 0.03 released

Version 0.03 of the pregame editor is finally here. As announced it includes staff name and staff nationality editing.

Besides this it's also possible to edit the contracts of non players, this includes changing their jobs. And finally changing of staff type is also possible.

This version also includes a couple of bug fixes, read the changelog for more details.
