## 1. Identity & commercial context

| Field | Detail |
|-------|--------|
| **First release** | **17 Sep 1993** — *Championship Manager '93* |
| **Developer** | Sports Interactive (Intelek credited on Amiga); company formalised **1994** |
| **Publisher** | Domark Software |
| **Platforms** | PC (DOS), Amiga, Atari ST |
| **Engine** | Text commentary — **BASIC → C rewrite** from CM1 |
| **Successor** | **CM2** (1995) — new engine, not a patch |

### SKU naming (community / retail confusion)

| Name | Typical meaning |
|------|-----------------|
| **Championship Manager '93** | Original 1993 box (Amiga reviews May–Jul 1993) |
| **Championship Manager 93/94** | Season data branding; often same product line |
| **End of Season Edition** | **1994** data refresh (MobyGames v4.04 on Archive.org) |
| **End of Season Data Disk** | Standalone data update (retail ads in Amiga press) |
| **Championship Manager Collection** | Bundle: 93/94 + update disk (Amiga Format price lists) |

⚠️ Magazines reviewed **'93** at launch; **93/94** often appears in **1994** ads/compilations without a separate review pass.

## 3. Expansions, update disks & spin-offs

CM93 era used **new disks / SKUs**, not downloadable patches.

| Product | Year | Type | Notes |
|---------|------|------|-------|
| **CM '93** | 1993 | Base game | Launch SKU |
| **End of Season Data Disk** | 1993–94 | Data disk | Retail ~£13–14 (Amiga press ads) |
| **CM Collection** | 1994 | Bundle | 93/94 + update disk ~£14 (Amiga Format ads) |
| **CM '94 End of Season Edition** | 1994 | Data refresh | Archive.org: `Championship_Manager_94_End_of_Season_Edition_v4.04_1993_Domark` |
| **World Cup Year '94** | 1994 | Compilation | CM + other football titles; AF cheat pages |
| **CM Italia** | 1993–94 | Spin-off | Serie A/B; Italian rules overlay — see CM2_REFERENCE §5.2 |
| **CM Italia '95** | 1995 | Data update | Italian spin-off refresh |
| **CM Norge** | 1993 | Spin-off | Norway |
| **Guy Roux Manager** | 1993 | Licensed variant | French league; Ubisoft/Intelek; CM1 engine lineage |

**Patch model:** No official FTP/internet patches. Updates = **buy new disk**, mail-in service, or End-of-Season edition.

### CM '94 / End-of-Season — deep notes (Round 8) ⚠️ mix primary + secondary

| Channel | Detail |
|---------|--------|
| **Mail-in update** | Send CM '93 disks + **£7.99** to **Intelek** for refreshed disks (community/RetroAffaire) |
| **Retail standalone** | Full **Championship Manager '94** package |
| **Disk count (Amiga)** | **3 floppies** vs original 2 — more data |
| **End-of-Season variant** | Includes **January transfers** + final 93/94 season stats (secondary) |
| **PC "Enhancement Pack" wording** | SI used enhancement language for stability/data fixes on PC re-releases (secondary) |
| **Bugfixes** | Season-end freeze and stability issues addressed (secondary) |
| **Easter egg** | Fictional **Mark Collis** + **Ferah Orosco** at Cambridge Utd — hidden superstars (secondary) |
| **Platform note** | CM '94 Amiga = **last Amiga CM expansion** before PC-centric CM2 |
